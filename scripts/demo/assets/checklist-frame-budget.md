# 帧预算排查清单（演示用）

> 这份清单只是演示附件，用来说明「文本类附件可以直接在阅读面板里读」。

## 开始之前

- [ ] 锁定机型与系统版本，记录在实验条目里
- [ ] 关闭动态调频，避免两次跑分不可比
- [ ] 确认采样窗口 >= 600 帧，丢掉前 60 帧

## 逐阶段

| 阶段 | 关注指标 | 常见坑 |
| --- | --- | --- |
| 几何提交 | Draw Call 数 | 合批被材质切换打断 |
| 阴影通道 | 级联数 / 分辨率 | 远处级联分辨率给太高 |
| 光照合成 | 带宽占用 | 中间纹理格式没降精度 |
| 后处理 | 通道数 | 相邻通道没合并 |
| 呈现等待 | 掉帧分布 | 只看均值会漏掉抖动 |
