文章板块
CARI · AI Community 功能介绍
【功能介绍】文章板块：好文章收进一个地方，AI 先读一遍，大家在同一份上读、画、评、问
网页、公众号、论文、PDF、电子书都能收；收进来就有干净正文和 AI 导读；阅读、翻译、划线、批注、评论、提问都发生在同一份文稿上，内容和模型都在内网。
①转发一篇公众号深度文贴链接，一分钟后大家读的是去掉广告的干净正文和导读，列表标明公众号与收录者。
②读一篇英文论文中文界面打开即中文，随时切回原文；不懂就问 AI，回答跳到原文段落。
③小组共读一份长报告各自划线批注，公开后同事在原文同一位置看到你的批注并回应。
④新同事熟悉方向按 7 个版块浏览，跟着热门和精选读；加入书架记进度，下次接着看。

现在的问题 链接散在群里，各读各的

  • 链接散在各个群里，一周后翻不到；谁读过没人知道。
  • 公众号文章头尾全是广告、图片防盗链，存下来只是链接。
  • 英文论文每个人各自翻译一遍，翻译结果不共享。
  • 读完的心得留在各自的笔记里，别人看不到。
  • 想知道「这篇讲了什么」，只能自己从头翻一遍。
现在 文章 /library
顶部 7 个版块；每条标明来源、收录者、阅读量；右栏热门与最新批注。

文章板块能做什么

收录贴链接或上传 PDF / EPUB / HTML / PPT / Word，不限大小；自动取正文、分章、封面、作者
公众号自动去掉「点击蓝字关注」「往期推荐」「扫码」头尾，图片转存内网不再失效
AI 导读摘要、大纲、要点、推荐问题，每章一句摘要，自动归类；每篇生成一次，全员共享
问答对着这一篇提问，回答附引用并可跳到原文；AI 模型可换成内部模型
阅读语言原文 / 中文 / English 一键切换，默认跟界面语言；标题一起翻；选中即译
划线批注四色划线写笔记；公开后同事在原文同一位置看到，可按人筛选、点赞、回复
阅读器连续滚动或分章，字号字体主题可调；PDF 原版 / 精读两种视图；进度跨设备
发现7 个版块加主题两级分类；热门、精选、继续阅读；来源与收录者一目了然
侧栏定位点一条最新评论或批注，侧栏打开真实页面并定位到那条评论、那段批注
社交分享评论可引用站内内容并有回复通知；评分、喜欢、书架；一键复制分享文案
权限管理公开 / 受限 / 私有三档；中英法三种界面；后台管分类、精选、AI 模型
规格：网页 + 5 种文件格式；7 个版块 / 16 个主题；中英法 3 种界面；AI 导读、译文、问答按篇缓存，全站只付一次。 问答只针对当前这一篇，不是跨库检索。
从群里转链接，变成在同一份文稿上读、画、评、问；AI 每篇只读一次，谁都能接着用。
