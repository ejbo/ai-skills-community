# 洞察图（Insight Figure）风格指南

来源：公众号「黄华书房」《再次遇到大时代》（2026-08-22）里的 12 张 PPT 截图（`ref/01..12`）。
用户对这批图"非常满意"，以后的图表都按这个类型做。

## 定位

一页 = **一句判断**（标题）+ **一张复合洞察图**（占满主体）+ **一句红色结论**（底部）。
图不是配图，图就是论证。看图的人不读正文也能把这页的判断复述出来。

## 五条铁律

1. **一页一图。** 主体区域整块给一张图。图可以由 2–3 个子面板拼成（表 | 曲线 | 曲线），但共享同一个论点。
   不做"左边图、右边一大段 bullet"——文字只以图内标注、面板小标题、底部一行灰底 band 出现。
2. **灰是结构色，红是结论色，蓝是对照色。**
   - 圆环 / 箭头 / 坐标轴 / 柱子 / 时间带 / 齿轮 / 漏斗一律灰：`#595959 #7F7F7F #A6A6A6 #D9D9D9 #F2F2F2`
   - 红 `#C00000` 只给：结论句、关键数字、手绘红圈红框、关键曲线（AI 能力线）、当前节点（NLP、2026）
   - 蓝 `#2F5597 / #9DC3E6 / #DEEBF7`：对照方（企业采用线、中国曲线）、阶段圆、金字塔底
   - 深蓝 `#1F3864`：数据柱。橙桃 `#FBE5D6`：引语框。全页红色面积 < 10%。
3. **图上讲故事。** 曲线沿线写阶段名（推理→编程→多模态→工具使用→Agents）；时间线上写事件和年份；
   排行榜上画一条穿过所有列的波浪线；大箭头上写"资源流动"；每个数据点都标数值；末端直接标系列名，不放图例。
4. **未来用虚线和问号。** 预测/推测节点 = 虚线圆或虚线段 + `?`（"RSI Engineering?"、"AGI?"、"30–50T?"、"2030"）。
5. **白底、黑字、细线。** 1px 黑/灰描边，圆角矩形 4–6px，无阴影、无渐变、无 3D、无 emoji。
   照片和 logo 可以贴，但只作时代/机构标识；没有真实图片就用文字框，**不要画假照片**。

## 版面

- 主体 ≈ 1208 × 480 px（去掉 `.sub` 副标题可多 28px）。子面板用 `.panes > .pane`，面板标题 `.pane-t`（14.5px 黑粗，关键短语 `<span class="k">` 红）。
- 面板宽度：表 | 曲线 | 曲线 = 260 / 1fr / 1fr；图 | 说明 = 62% / 38%；全宽图直接一个 `.fig`。
- 图下方允许 **一条** `.band`（灰底）放 1–2 条 bullet，或一条 `.concl`（红字居中）放子结论；不要两条都放。
- 页面级红色结论 = 框架自带的 `.bar`（红底白字）。一页只有一句结论，不要在 band 里再写一遍。

## HTML / SVG 实现约定

- 图 = inline SVG，`viewBox` 固定（比如 `0 0 740 420`），`width/height 100%`，`preserveAspectRatio="xMidYMid meet"`。
- SVG 里的字：11–14px，`fill:#333`；标题/关键 14px `font-weight:700`；红字 `fill:#C00000`。
- 曲线 `stroke-width 2.5`，未来段 `stroke-dasharray="5 4"`；坐标轴 `stroke:#7F7F7F stroke-width:1`；网格不画。
- 手绘红圈：`<ellipse fill="none" stroke="#C00000" stroke-width="1.6" transform="rotate(-8 cx cy)">`。
- 圆环（A2）：`<circle r="52" fill="none" stroke="#BFBFBF" stroke-width="14">`，环心两行字。
- 箭头：`<marker>` 实心三角，灰；大弯箭头用粗灰 `path` + 三角头。
- 数据驱动的图（折线 / 柱 / 气泡）先用 python 算坐标再写 SVG，不要手估。
- 来源角标 `.src`（右下 10px 斜体灰，如 `Source: BOND`）。
- 说明文字（面板标题、band、box）用 HTML，不要塞进 SVG。

## 写作口径

短句，具体数字，同事之间说话的语气。不用"颠覆性 / 革命性 / 划时代"，不用三段排比，不用格言，
不用感叹号。红色结论是大白话判断，不是金句。图内标注 ≤ 12 字。
