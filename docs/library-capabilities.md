# 文章板块（/library）能力清单与推介口径

> 面向用户/领导的能力清单，做胶片、写介绍直接取用，不要再回代码调研。每条都按 2026-10-09 的代码核对过；
> 改了产品请同步改这里。同类文档：`docs/events-capabilities.md`。

## 一句话

把团队看到的好文章收进一个地方，AI 先读一遍，大家在同一份上读、画、评、问。
三件事：**收得进**（贴链接/传文件，几秒得到正文、章节、封面、导读）· **读得懂**（中英自动翻译、选中即翻、对着这篇问 AI 且回答带原文定位）· **留得下**（划线批注留在原文旁边，别人看得见、能回应；谁读过、读到哪有记录）。

## 现在的问题（痛点）

- 链接散在各个群里，一周后翻不到；谁读过、读到哪没人知道。
- 公众号/外网文章打开慢、头尾广告、图片防盗链，存下来只是链接。
- 英文论文与中文解读混读，每人各自翻译一遍，结果不共享。
- 读完的心得留在各自笔记里；想问「这篇讲了什么」只能自己翻。

## 它是什么

内网共享阅读库。任何成员丢链接或上传文件 → 抓正文、分章、封面、作者 → AI 读一遍生成导读并归类（每篇一次、全员共享）→ 所有人在同一份文稿上阅读、翻译、划线、批注、评论、向 AI 提问。内容与模型都在内网，AI 可配内部模型。

## 典型场景

1. **转发公众号深度文**：贴链接 → 自动去「点击蓝字关注/往期推荐/扫码」头尾、图片转存 → 一分钟后大家读到干净正文 + 导读；列表标「公众号 · 账号」和收录者。
2. **读英文论文**：中文界面打开即中文，原文/中文/English 一键切换；选中一句翻译；问 AI，回答附引用并跳到原文段落。
3. **小组共读长报告/书**：各自划线批注，开「公开我的笔记」后同事在原文同一位置看到并可点赞回复；首页「最新评论与批注」点开侧栏直接定位到那段。
4. **新同事熟悉方向**：7 个版块 → 主题浏览；热门（近一周互动）、精选；书架记进度，「继续阅读」接着看。

## 功能一览（六组）

**收录**：网页（博客/公众号/新闻）+ PDF/EPUB/HTML/PPT/Word，文件大小不限；自动正文/分章/封面/作者/发布时间；同链接、同文件去重；公众号首尾广告去除 + 图片转存；收录者可改标题/作者/摘要/分类/封面、逐章编辑正文，改过的不被重新解析覆盖。

**AI**：导读（摘要/大纲/要点/推荐问题）+ 每章一句摘要 + 自动归类，每篇生成一次全员共享；对着这篇提问，回答附引用可跳原文；导读中英双语；后台可切内部模型并自检连通性。

**阅读**：沉浸式阅读器，连续滚动/分章；字号/字体/行高/宽度/浅色·护眼·深色；PDF 原版（浏览器原生）与精读（可划线批注问答）两视图；阅读语言 原文/中文/English 默认跟界面语言，标题同翻，正文自动翻译共享缓存；选中即翻译；四色划线 + 笔记；公开批注按人筛选/搜索/原文顺序·最新·最热排序，点赞回复；进度跨设备记住；目录、相似文章、下载原文件。

**发现**：7 版块 / 16 主题两级分类（管理员可调）；类型/排序筛选；列表/卡片；全站搜索；热门四视图（最热=近 7 天互动按时间衰减计分、最多评论、最多阅读、最多收藏）；精选、继续阅读、最新评论与批注（点开在侧栏加载真实页面并定位）；每条显示来源（公众号·账号/站点/PDF）、收录者、阅读量、评论数；链接即标题。

**社交与分享**：评论用全功能编辑器，可引用站内文章/视频/活动/帖子，回复有站内通知；评分、喜欢、书架（在读/读完统计）、在读名单、公开笔记名单、悬停名片；一键分享复制「标题/来源/作者/AI 导读/链接」。

**权限与管理**：公开 / 受限（申请阅读、收录者审批）/ 私有；身份信息按权限脱敏；中英法三语界面；W3 登录、内网部署；后台：分类、精选、重新处理、AI 模型设置。

## 为什么用它

- **个人**：少翻一次译、少找一次链接；读过的、划过的、问过的都留在这篇上。
- **团队**：讨论发生在原文旁边而不是群聊里；谁在读、谁读过、谁批注了什么一目了然；知识从群聊链接变成能检索回看的库。
- **管理者**：看得到什么在被读、谁在贡献；内容、批注、模型调用都在内网；AI 成本按篇一次。

| 对比 | 它们 | 文章板块 |
| --- | --- | --- |
| 微信收藏 / 书签 | 存链接，只有自己可见，原页会失效 | 存干净正文+图片+导读，团队共享，原文失效也还在 |
| 网盘 / 群文件 | PDF 要下载再开，批注各在各机 | 在线精读、划线、问答、翻译，批注在原文位置共享 |
| Readwise / Pocket | 数据在外网，不懂公众号，与内部账号不通 | 内网私有、模型可换、公众号专门处理、与社区账号/通知/讨论打通 |

## 如何开始

1. 「文章」→「添加内容」，贴链接或上传文件。2. 等几秒看导读，必要时改分类/标题。3. 加入书架开始读；划线、批注、评论；用「分享」发到群里。管理员在后台配模型、分类、精选。

## 演示时要说清的边界（防穿帮）

- AI 问答只针对当前这一篇，**不是**跨整个库的检索问答。
- 导读与翻译由模型生成，可能有疏漏，原文随时一键可见。
- 公众号广告去除是规则式的，个别特殊排版可能漏，收录者可手动修正章节。
- 没有「订阅更新通知」「跨库问答」「长视频」这类能力，别顺嘴说。
